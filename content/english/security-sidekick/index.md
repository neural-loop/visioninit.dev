## How It Works

1.  **Choose & Consult:** Select the plan that seems right and schedule an initial consultation using the buttons above. This helps us confirm the fit and understand your immediate needs.
2.  **Onboard (Steady Shot):** For the monthly plan, we'll have a brief kickoff to set up communication channels and understand your environment/priorities.
3.  **Request:** Submit your security question or review request. (For Sure Shot, this is your single included request. For Steady Shot, submit as needed via the agreed channel).
4.  **Receive:** Get expert feedback, reports, or guidance within the typical turnaround time.
5.  **Iterate (Steady Shot):** Continue submitting requests. Manage your monthly subscription (pause/cancel) as needed.

## Frequently Asked Questions (FAQ)

{{< accordion title="What's the main difference between the plans?" >}}
**Sure Shot** is a one-time purchase for a single, defined security request. **Steady Shot** is a monthly subscription providing ongoing access for unlimited requests (processed one at a time).
{{< /accordion >}}

{{< accordion title="Can a Sure Shot request cover a full penetration test?" >}}
No. Both plans are designed for focused reviews, guidance, and configuration checks. Full penetration tests, large-scale architecture reviews, or incident response require separate, project-based engagements.
{{< /accordion >}}

{{< accordion title="What types of requests are best for Sure Shot?" >}}
*   Reviewing a specific pull request (within reasonable scope).
*   Asking for guidance on configuring a particular service securely (e.g., an S3 bucket policy).
*   Getting a second opinion on a vulnerability finding from an automated scanner.
*   Clarification on a specific security best practice.
    {{< /accordion >}}

{{< accordion title="How are requests prioritized for Steady Shot?" >}}
Requests are typically handled in the order they are received in your queue. We process one active request at a time per subscription.
{{< /accordion >}}

{{< accordion title="How do we communicate?" >}}
Initial contact is via the consultation scheduler. For ongoing Steady Shot clients, we establish a primary asynchronous channel (like email or a project board) during onboarding.
{{< /accordion >}}

{{< accordion title="Is there a limit to request complexity for Steady Shot?" >}}
While requests are unlimited, each should be reasonably scoped. Extremely large tasks (e.g., "Review our entire codebase") might be broken down or proposed as separate project work outside the subscription. We'll discuss scope during onboarding or if a request seems overly large.
{{< /accordion >}}

{{< accordion title="What if I need help outside typical business hours?" >}}
The Security Sidekick service operates during standard business hours (US Eastern Time, Monday-Friday, excluding holidays). Urgent, off-hours support or incident response would fall outside the scope of these subscription plans.
{{< /accordion >}}
